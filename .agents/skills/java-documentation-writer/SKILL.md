# Java Documentation Writer 

Use this skill when documenting Java source files.

## Instructions 

1. Use Javadoc best practices. 
2. Fix English lexical and grammar errors. 
3. If an original documentation for a source file already exists, do not rewrite completely focus on improving
the English of the existing documentation. 
4. All files must match the same style of documentation.
